# Gießelink, Emu48 Manual

The user manual of Emu48 (current version, copyright 2025), text conversion
of the HTML. Read in full; cite by section number. Hardware-relevant facts
are on [[emulators/emu48]]: emulated models, ROM image formats and the I/O
area in ROM dumps, memory cards, serial and IR ports, the IR printer over
UDP, beeper and CPU speed measurement, object load/save format, DDE format.
