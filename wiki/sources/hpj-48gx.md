# HP Journal, August 1994: the HP 48G/GX

The August 1994 Hewlett-Packard Journal article on the HP 48G/GX (17 PDF
pages, text layer present). Read for the CPU and memory facts
(2026-10-05); the software chapters were skimmed.

Cite as `(src: [[sources/hpj-48gx]] PDF p. N)`.

## CPU (PDF p. 4)

- The new CPU is produced in a different CMOS process with on-board
  voltage regulation; "these improved voltage characteristics and several
  low-level optimizations allow the new CPU to operate at twice the speed
  of its predecessor. This speed increase gives it a 4-MHz bus rate."
- Packaged in a 160-pin quad flat pack.
- The faster CPU let the software team add graphical routines that would
  have been too slow on the 48SX.
- The 48G and GX share one ROM code set; the RAM size serves as a product
  type identifier.

The measured throughput is well below twice the 48SX's: see
[[questions/instruction-speed-vs-hardware]].
