# Gießelink, Emu48 25 Years Anniversary

Web page, not in `raw/` (fetched 2026-10-05). The Emu48 maintainer's
history of the emulator, 1997-2022. Prose only, no code. Read for the
38G/39G/40G parts.

- The 38G (1995) is "based on the HP-48 G-series hardware but with one
  important difference not allowing to run the HP-38G ROM image on an
  unmodified Emu48". The page does not say what the difference is.
- Jean-Yves Avenard released a modified Emu48 called Emu38 plus an SDK in
  1998; the 38G was folded into Emu48 1.15. In 1999 no 38G ROM image was
  downloadable; users uploaded their own. Emu48 1.16 added the 38G with
  Detlef Müller's special ROM and 64 KB of RAM (Emu48 KML model `6`).
- The 39G and 40G (2000) are based on the 49G (1999); **both use the same
  ROM image**. "The final hardware only contained 1MB ROM and 256KB of RAM
  instead of 2MB Flash Memory and 512KB RAM like in the HP-49G."
- Emu48 supports the smaller ROM since 1.19 and full 39G hardware
  emulation since 1.21. Gießelink wrote the 39G ROM upload aplet (an
  e-lesson) using Emu48 as the development platform.
