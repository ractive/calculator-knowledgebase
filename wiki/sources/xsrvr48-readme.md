# Graves, XSrvr48 1.1 ReadMe

Readme of the XModem server library for the HP 48 (the `.hp` binary stays in
the zip). Facts: the HP 48 has no built-in XModem server; XSrvr48 provides
one, written with de Brébisson's support, and works with the HP Xmodem
Connectivity Kit 1.0 and 2.0; install in port 0 or 1, not 2 or higher.
Conn4x's own ReadMe adds the product lineage: HP-48 PC Link, HP PC
Connectivity Kit (Kermit), HP Xmodem Connectivity Kit 1.0 (49G only), Conn4x
2.0 = Xmodem Kit 2.0 with HP 48 support. Same non-commercial terms.
