# HP-27S Owner's Manual

Edition 2 (February 1988; edition 1 was October 1987), reorder number
00027-90028. A 264-page scan with hpcalc.org's OCR as a text layer
(per-page text in `raw/manuals/text/hp27s-om-en.txt`, block N = PDF page
N). Public copy: <https://literature.hpcalc.org/community/hp27s-om-en.pdf>.
Book page = PDF page - 6 in the body.

Read for [[hardware/hp27s]]: the keyboard figure, chapter 1, the clock
pages of chapter 7 and appendix A. Status skimmed.

## Where the useful parts are

- **PDF p. 2**: colour keyboard drawing with 16 callouts; every shifted
  label in blue.
- **p. 21 (book 15)**: power, ten-minute auto-off, contrast (hold CLR,
  press + or −).
- **p. 26 (20)**: table of the five annunciators: shift, print,
  appointment, low battery, RAD.
- **p. 27-28 (21-22)**: the blue shift key, INPUT usable in place of =,
  menu keys with fixed shifted functions (√x, x², ...).
- **p. 41-45 (35-39)**: the ALPHA and ALPHA-edit menus.
- **p. 59-60 (53-54)**: degrees and radians, the RAD annunciator.
- **p. 144-149 (138-143)**: clock, SET, ADJST, ten appointments.
- **p. 197-205 (191-199)**: batteries, MEMORY LOST, machine reset,
  erasing continuous memory, clock accuracy, self-test ("OK-27S-E") and a
  factory test on the fourth menu key.
