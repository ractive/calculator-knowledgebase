# HP 49G Advanced User's Guide

Version 1, (c) Hewlett-Packard 1999 (PDF made 2005). 198-page scan without a
text layer. Page mapping examples: p. 1-4 = PDF 16, p. 2-1 = PDF 19,
p. 5-15 = PDF 55, p. 8-2 = PDF 78, p. 13-2 = PDF 118, p. 14-61 = PDF 183.
Read: contents (PDF 5-10) and chapter 2 "System flags" (p. 2-1 to 2-4,
PDF 19-22) as page images; the whole guide through a local OCR pass
(tesseract) searched for flag numbers. The flag statements used were read
from the OCR text; p. 1-5, 2-1 to 2-4, 5-15 and 8-2 were also checked as
page images.

- Chapter 2 explains the System Flags browser (MODE, FLAGS), SF, CF, FS?,
  FC?, FS?C, FC?C and says there are 128 user flags. It has **no list of the
  system flags**: it refers to the separate *HP 49G Pocket Guide* for that
  (2-1); the flag pages of that booklet are in the library now as
  photographs, [[sources/hp49g-pocket-guide]].
- Flag meanings stated in passing: -3 and -105 in nearly every chapter 14
  (CAS) entry, -103 and -116 in some; -11/-12 base table (8-2); -54 for RANK
  and DET (5-15); -60 (2-1); -61 (13-2); -90 catalog font (1-4, 1-5); -95
  algebraic or RPN without polarity (2-1).
- Chapter 14 is an alphabetical CAS command reference with input, output,
  required flags and an example per command.
