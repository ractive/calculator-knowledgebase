# HP-28S Owner's Manual

Edition 5 (August 1989; edition 1 was November 1987), reorder number
00028-90066. A 342-page scan with hpcalc.org's OCR as a text layer
(per-page text in `raw/manuals/text/hp28s-om-en.txt`, block N = PDF page
N; the OCR drops most key glyphs, so read the key names off the page
images). Public copy:
<https://literature.hpcalc.org/community/hp28s-om-en.pdf>. Book page =
PDF page - 2.

Digested for [[hardware/hp28s]]: chapter 1 (book p. 18-33), the start
of chapter 15 (p. 149), chapter 18 (p. 166-169), the low-memory part of
chapter 20 (p. 188-189), the entry-mode part of chapter 24 (p. 207-208),
chapter 25 (p. 215-219) and the batteries and self-test parts of
appendix A (p. 286-291). The rest (the maths, the Solver, plotting,
programming) was not read.

## Where the useful parts are

- **p. 19-20**: printer port and battery door; IR printing; three
  N-cell batteries; ten-minute auto-off; ON doubles as ATTN; the memory
  reset chord and how to back out of it.
- **p. 21**: contrast with ON held; the stack example (15 ENTER 23 +)
  with display pictures on p. 22-24.
- **p. 26-27**: annotated drawing of both keyboards and the display,
  every key's shifted label; p. 29-31 explain the callouts, with the
  table of seven annunciators on p. 29.
- **p. 149**: printing the display with ON held; the HP 82240A printer.
- **p. 166-169**: command line (23 characters per row), the cursor menu
  on the six menu keys, the entry keys including the cursor-menu key and
  Menu Lock.
- **p. 188-189**: 32 Kbytes of user memory, about 400 bytes of it for
  the system; the low-memory messages.
- **p. 215-219**: the system operations table (all ON chords), System
  Halt, Memory Reset, the repeating self-test ("OK-28S") and the
  keyboard test.
- **p. 286-291**: batteries, low-battery annunciator, the factory test
  on ON + down arrow, the repeating test with a printer.
