# HP 39G / HP 40G

Two models on one board design and **one ROM image**, derived from the 49G
with less memory and a mask ROM instead of flash (src:
[[sources/giesselink-emu48-25-years]]). The 40G adds a computer algebra
system and drops the IR port (src: [[sources/hp39g40g-ug]] 1-29, 16-5).

## Summary

| Item | 39G | 40G |
| --- | --- | --- |
| Released | 2000 (src: [[sources/giesselink-emu48-25-years]]) | 2000 |
| Base design | 49G (src: [[sources/giesselink-emu48-25-years]]) | same |
| CPU | Yorke Saturn core, 4 MHz (src: [[sources/wikipedia-hp39-40]], weak); Emu48 drives it with `Hardware "Yorke"` (src: [[sources/kml20]] Global) | same |
| ROM | 1 MB, shared by both models (src: [[sources/giesselink-emu48-25-years]]) | same image |
| RAM | 256 KB (src: [[sources/giesselink-emu48-25-years]]; [[sources/wikipedia-hp39-40]]) | same |
| Display | 131 x 64, same controller; ghost registers at #8068D like the 48G/49G (src: [[sources/saturn-tutorial]] p. 165-166) | same |
| Keyboard | 49G matrix (src: [[sources/kml20]] OutIn codes HP49G) | same matrix (key layout assumed identical, see below) |
| IR | yes, to another 39G (src: [[sources/hp39g40g-ug]] 16-5) | **none**; ships with a PC adapter and a unit-to-unit cable (16-5) |
| Serial | cable to a PC or "aplet disk drive" (16-5) | same |
| Power | 4.5 V dc, 60 mA max (src: [[sources/hp39g40g-ug]] R-7) | same |
| Emu48 model | `E`, `Class 39` (src: [[sources/kml20]] Global) | `E`, `Class 40` |

## Memory map

What the sources give:

- 1 MB ROM and 256 KB RAM "instead of 2MB Flash Memory and 512KB RAM like
  in the HP-49G" (src: [[sources/giesselink-emu48-25-years]]).
- Display ghost registers at #8068D, #80692, #8069A, #80695, the same
  addresses as the 48G and 49G (src: [[sources/saturn-tutorial]] p. 166).
- Emu48 handles ROMs smaller than 2 MB on the 49G-type hardware by
  mirroring them (src: [[emulators/emu48]] CHANGES SP19); it supports "the
  smaller ROM" since 1.19 and full 39G hardware since 1.21 (src:
  [[sources/giesselink-emu48-25-years]]).

What follows from the 49G page ([[hardware/hp49g]]) and is **inference,
unverified**:

- RAM: 256 KB is exactly the 49G's internal RAM (IRAM, HOME and port 0) on
  NCE2 at #80000-#FFFFF; the ghost registers at #8068D sit in that window.
  The 49G's other 256 KB (ERAM, port 1, on CE2 and NCE3) is what was cut.
- ROM: 1 MB is 8 banks of 128 KB on NCE1, reached through the same CE1
  bank latch as the 49G (low window #00000-#3FFFF, high
  window #40000-#7FFFF). With half the banks missing, a 4-bit high-window bank
  number would see banks 8-15 mirror 0-7, which is what Emu48's mirroring
  does.
- No flash: mask ROM cannot be written, so the 49G's NCE3 plus #11C bit 3
  write path has nothing behind it. Whether the ROM ever probes it is
  unknown.
- CE2 and NCE3: probably unconnected. The ROM's CONFIG sequence at boot
  will show what it expects.

Filed as [[questions/hp39g-40g-memory-map]], together with the layout of
the published ROM file.

## Keyboard

Emu48 uses its 49G OutIn table for the 39G and 40G (src: [[sources/kml20]]
OutIn codes HP49G). The 39G keyboard is the 49G's shape, row for row (src:
[[sources/hp39g40g-ug]] 1-3 figure). The table puts each 39G key at the
matrix position of the 49G key in the same place: an **inference**, as for
the 38G. The reset chords fit it: ON plus the third menu key resets, ON
plus the first and last menu keys clears memory (src:
[[sources/hp39g40g-ug]] R-4, R-5), the 49G's ON-F3 and ON-F1-F6 positions.
The user's guide shows only 39G pictures; the 40G differs in a CAS menu
label (1-2 note), so the same physical layout is assumed for the 40G
(unverified).

#8000 for any OUT. 49G names and codes from [[hardware/keyboard]] "HP49G

## Display

Same controller and LCD (src: [[sources/saturn-tutorial]] p. 165). Emu48
contrast: reset value 12 (the 49G uses 14), keyboard range 9-24 (src:
[[sources/kml20]] LCD). Power-on contrast 12, observed on the 39G/40G ROM
after a cold start (observed in saturnus 2026-10-07; saturnus renders it at about 90 % darkness).

## Serial, IR and PC link

- 39G: IR to another 39G within 5 cm, or cable to a PC or aplet disk
  drive; 40G: cable only, with a PC adapter and a unit-to-unit cable in the
  box (src: [[sources/hp39g40g-ug]] 16-5).
- The calculator drives PC transfers: it lists the PC's current directory
  and the user ticks the aplets to receive (16-5), as on the 38G
  ([[hardware/hp38g]]).
- No protocol is named in the guide (no Kermit, no XModem). Open:
  [[questions/hp38g-39g-transfer-protocol]].
- The UART and IR registers are presumably the 49G's (inference).

## Model detection

The 39G and 40G run the same ROM (src:
[[sources/giesselink-emu48-25-years]]), yet the 40G shows a CAS and has
no IR (src: [[sources/hp39g40g-ug]] 1-2, 1-29), and Emu48 needs a `Class
39` or `Class 40` line to tell them apart (src: [[sources/kml20]] Global).
So the ROM reads something in hardware that differs between the two
boards. What it reads is not documented in any source read:
[[questions/hp39g-40g-model-detection]].

## First boot

- Reset: ON plus the third menu key, or the reset hole; memory clear: ON
  plus the first and last menu keys; a five-step recovery sequence ends
  with removing the batteries (src: [[sources/hp39g40g-ug]] R-4, R-5).
- What the ROM shows on a cold start with blank RAM is not documented:
  observe it when booting the ROM.

## ROM image

- hpcalc.org offers "HP 39/40 ROM", `rom3940.zip` (563,090 bytes,
  <https://www.hpcalc.org/details/6739>), containing `rom.39g`, 2,097,152
  bytes, dated 2000-11-19, author "Hewlett-Packard" (src:
  [[sources/hpcalc-rom-listings]]). Two older packages carry a 39G/40G
  **beta** ROM: `emu48-39.zip` (details 4272) and HP's own `emu39.zip`
  (details 4273).
- 2,097,152 bytes is either 1 MB unpacked (one nibble per byte) or 2 MB
  packed (two nibbles per byte, the 1 MB mirrored once). Uploaded 39G ROMs
  are packed and Emu48 accepts them renamed, or unpacked after its Rom2emu
  tool (src: [[sources/emu48-manual]] 3.1). Which one hpcalc ships is a
  check to make after download: every byte below #10 means unpacked.
- Permission: as for the 38G, the page has no HP permission sentence,
  unlike the 48 ROM pages; the Emu48 manual says the 39 and 40 ROMs have
  been "freely available" since fall 2000 without a distribution licence
  (src: [[sources/hpcalc-rom-listings]]; [[sources/emu48-manual]] 3).

## Facts settled while building saturnus (2026-10-05)

Observed by booting hpcalc's `rom.39g` on the clean-room saturnus emulator.
There is no oracle, so none of this is checked against hardware or another
emulator.

- **The image.** `rom.39g` is the 1 MB ROM **unpacked**, one nibble per
  byte (every byte is below #10). SHA-256
  `69220f42d5e90dd8825e7d1596d9eaca490ee6a7a52a3b8b96469a5f3d3f627f`. It
  is an upload: nibbles #00100-#0013F hold I/O register values
  (`0 F D F 3 0 0 0 2 0 0 3 0 0 4 ...`) where the 48GX and 38G images hold
  zeros, so an emulator should zero them as Emu48's Convert does. The
  current download link is `https://www.hpcalc.org/hp39/pc/rom3940.zip`
  (the details page links `../hp39/pc/rom3940.zip`).
- **Wiring that boots.** The 49G design with the cuts the sources name:
  the ROM on NCE1 behind the 49G's CE1 bank latch (latch bits as on the 49G,
  Sousa's assignment, see [[hardware/hp49g]]), 256 KB RAM on NCE2, nothing
  on CE2 or NCE3, no flash write path, 4 MHz.
- **CONFIG sequence.** The cold start configures HDW at #00100, then NCE2
  as size #80000 at #80000 (configured, unconfigured, configured again).
  CE2 and NCE3 are never configured. CE1 is configured only around a bank
  switch: `CONFIG #FF000`, `CONFIG #7E0nn` (a 4 KB window at #7E000), one
  access at #7E0nn, then `UNCNFG`. So the ROM switches banks the 49G way,
  by an access whose address bits A1-A6 are latched.
- **Banks.** The ROM runs with latch 9 (low view bank 0, high view bank 9)
  and scans latches 0-7 (high banks 0-7) during the cold start. A 1 MB ROM
  has 8 banks of 128 KB, so high bank 9 must be bank 1: the high-view bank
  number is taken modulo 8 (banks 8-15 mirror 0-7). With latch 9 every CPU
  address below #80000 equals its file offset.
- **Cold start.** With blank RAM the ROM shows a "Memory Clear" box with
  an OK softkey (menu key 6); OK leads to HOME. `6 * 7 ENTER` on the keys
  of the table above shows `6*7` and 42, which confirms the digit,
  operator and ENTER rows. ON plus menu key 3 resets to HOME (history
  display empty); ON plus menu keys 1 and 6 brings back the "Memory Clear"
  box.
- **Model strap: #11A bit 3.** See [[questions/hp39g-40g-model-detection]].
  With that bit read as 1 the ROM puts a CAS label on menu key 6 at HOME,
  the 40G's look.
- **PC link.** SEND to a disk drive (APLET, SEND, third entry after
  "HP39/40 (IR)" and "HP39/40 (Cable)") speaks Kermit as a client: see
  [[questions/hp38g-39g-transfer-protocol]].
- **Letters.** The 39G alpha letter positions are in no source read; not
  tested.

## Alpha letters (2026-10-05, corrected the same day)

What ALPHA then each key types, observed by booting the 39G ROM
(`rom.39g`) on the clean-room saturnus emulator. Keys are named by the
function they perform on the same ROM (ALPHA then SIN types E, plain SIN
types `SIN(`), so the table does not depend on saturnus' inferred matrix
positions. This is emulator against ROM, not hardware:

| Key | Letter | Key | Letter | Key | Letter | Key | Letter | Key | Letter |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| VARS | A | MATH | B | d/dx | C | X,T,θ | D | DEL | - |
| SIN | E | COS | F | TAN | G | ln | H | log | I |
| x² | J | x^y | K | ( | L | ) | M | ÷ | N |
| , | O | 7 | P | 8 | Q | 9 | R | × | S |
| ALPHA | - | 4 | T | 5 | U | 6 | V | − | W |
| SHIFT | - | 1 | X | 2 | Y | 3 | Z | + | space |
| ON | - | 0 | θ | . | `:` | (−) | `;` | ENTER | - |

- A second ALPHA cancels alpha mode rather than locking it, as on the 38G
  ([[hardware/hp38g]]), so every letter is ALPHA then its key. SHIFT
  ALPHA then a key types the lowercase letter (SHIFT ALPHA VARS gives
  `a`).
- The 40G ROM image is the same; the 40G types the same letters.
- The first reading of the user's guide figure (page 1-3, src:
  [[sources/hp39g40g-ug]]) put every letter one key row lower: A-D on
  SIN..ln, ..., X-Z on 0 . (−), space on ENTER, and θ : ; "below the
  bottom row". The ROM shows the letters belong to the key above. The
  figure evidently prints each letter below and to the right of its key.
