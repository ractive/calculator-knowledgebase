# HP-42S Owner's Manual

Edition 7 (March 1994), 362 pages, a scan with hpcalc.org's OCR as a text
layer (per-page text in `raw/manuals/text/hp42s-om-en.txt`, block N = PDF
page N). Public copy: <https://literature.hpcalc.org/community/hp42s-om-en.pdf>.
Book page = PDF page - 9 in the body.

Read for [[hardware/hp42s]]: the function preview. Status skimmed.

## Where the useful parts are

- **PDF p. 84 (book 75)**: "Function Preview and NULL". Holding a key
  that executes a function shows the function's name; held "for about a
  second", NULL replaces the name, stays until the key is released, and
  the function is not executed. Released before NULL, the function runs.
