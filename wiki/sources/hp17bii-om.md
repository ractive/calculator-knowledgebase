# HP 17BII Financial Calculator Owner's Manual

Edition 2 (April 1991; edition 1 was December 1989), part number
00017-90046. A 300-page colour scan with hpcalc.org's OCR as a text layer
(per-page text in `raw/manuals/text/hp17bii-om-en.txt`, block N = PDF
page N). Public copy:
<https://literature.hpcalc.org/community/hp17bii-om-en.pdf>. HP's own
scan of the same manual (`/official/hp17bii-om-en.pdf`, 13 MB) has no text
layer and was not kept. Book page = PDF page - 6 in the body.

Read for [[hardware/hp17bii]]: the keyboard figure, chapter 1 and
appendices A and D. The application chapters (TVM, cash flows, bonds,
statistics, Solver) were not read, hence status skimmed.

## Where the useful parts are

- **PDF p. 2**: keyboard photograph with 18 numbered callouts (cursor,
  menu keys, shift key, ON, MEM, SHOW, ENTER in RPN mode, backspace, the
  RPN register keys, EXIT and MAIN, DSP, MODES).
- **p. 22 (book 16)**: power on and off, ten-minute auto-off, low-battery
  symbol, contrast (hold CLR, press + or −).
- **p. 23 (17)**: the display: calculator line, menu labels, four
  annunciators (shift, printer, alarm, battery) and the shift key.
- **p. 33-34 (27-28)**: the ALPHA menu: letters typed with two menu-key
  presses; the ALPHA-Edit menu.
- **p. 37-38 (31-32)**: DSP, SHOW and the shifted RND.
- **p. 39 (33)**: MODES menu: beeper, printer adapter, double space, ALG
  and RPN.
- **p. 136-142 (130-136)**: TIME menu: clock, SET, ADJST, ten appointments
  with alarms, acknowledgement, past-due behaviour.
- **p. 220-227 (214-221)**: batteries and MEMORY LOST, machine reset,
  erasing continuous memory, clock accuracy, self-test.
- **p. 256-259 (250-253)**: appendix D, setting RPN mode and where the RPN
  functions sit on the keyboard.
