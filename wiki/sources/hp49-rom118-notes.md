# HP 49G ROM 1.18 release notes (quoted on hpmuseum.org)

Forum post of 2001-04-23 quoting the release notes shipped with ROM 1.18.
Two parts: "What's new from Release 1.16" and "What's new from Release 1.10".
XSERV, XGET, XPUT and ROMUPLOAD appear in the second part, so they arrived
after 1.10 (in 1.16 or earlier), not in 1.18 itself.

- XSERV puts the calculator in XModem server mode; commands: P put a file,
  G get a file, E execute the command line, M get the calculator memory, L
  list the files in the current directory.
- XGET / XPUT: get from / put to an XModem server, argument a global or local
  name.
- ROMUPLOAD: act like HP's FDP program to upgrade another 49G's ROM; 9600 bps
  required.
- 1.18: "Kermit in ASCII mode handles \"" (a fix).

Secondary (forum transcription) but the only text form of the notes.
