# HP-17B Owner's Manual

Edition 1 (August 1987), manufacturing number 00017-90002. A 276-page scan
with hpcalc.org's OCR as a text layer (per-page text in
`raw/manuals/text/hp17b-om-en.txt`, block N = PDF page N). Public copy:
<https://literature.hpcalc.org/community/hp17b-om-en.pdf>. Its page
numbering matches the 17BII manual ([[sources/hp17bii-om]]) closely, as
the 17BII manual is a revision of it; book page = PDF page - 6 in the body.

Read for [[hardware/hp17bii]] (the 17B differences): the keyboard figure,
chapter 1 and appendix A. Status skimmed.

## Where the useful parts are

- **PDF p. 2**: keyboard drawing with 15 callouts; the colour drawing
  shows which keys carry shifted labels.
- **p. 22-23 (book 16-17)**: power, contrast, the four annunciators,
  shift key.
- **p. 136-142 (130-136)**: clock, appointments and alarms, as on the
  17BII.
- **p. 220-226 (214-220)**: batteries, MEMORY LOST, machine reset,
  erasing continuous memory, clock accuracy, self-test ("OK-17B-E").
- The 17B has no RPN mode: the manual has no RPN appendix and no MODES
  entries for ALG or RPN.
