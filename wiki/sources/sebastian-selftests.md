# Sebastian, HP calculator self-tests

Mike Sebastian's page of HP self-test procedures, part of his calculator
self-test collection (© 2000-2007, "last updated July 23, 2007"), read
on 2026-10-25. A web page, not in `raw/`:
<https://rskey.org/~mwsebastian/selftest/hp_test.htm>. One section per
model or family: how to start each test, what it shows, how to stop it.
It warns, for the 38G, 39G and later models, that the tests may clear
data memory, programs and mode settings. Collected from his own and
readers' calculators; not an HP document.

What it says for the models of this wiki (our words):

- **28C/S**: ON + ◀ (the fifth menu key, "E") the repeating test, ON + ▲
  ("C") stops it; ON + ▼ ("D") a full test stepped by any key until
  KEYBOARD TEST, then all keys in order, left keyboard first; stopped
  the same way.
- **Pioneers** (27S, 17B, 17BII and the other high-end Pioneers): the
  ON-line key (C, CLR or EXIT) + fifth menu key the continuous test,
  that key + third menu key stops it; + fourth menu key a full test
  stepped by any key to after the copyright notice, then "KBD" (or "01")
  and every key in order, ending in an OK message; stopped the same way.
- **38G**: like the 48 (ON+E continuous, briefly "OK-38"; ON+D the
  individual tests, no menu, a vertical line; ON+C leaves both); the
  KBD2 key order is listed.
- **39G**: ON+E continuous ("HP 39/40 OK" at the end of a pass), ON+C
  stops it; ON+D a menu of seven tests (Hard, Cpu, Kbd1, Kbd2, FullRAM,
  RS232, IR), left with ON (which reboots) or ON+C; ON+F a quick test
  (ERAM, CPU, RAM, display, Kbd2, RS232, IR), left with ON+C. Kbd1 wants
  every key in order and shows a hex code for a wrong one; Kbd2 wants the
  six menu keys, SYMB, PLOT, NUM, HOME, APLET, VIEWS, ◀ and the comma.

The 40G and 19BII are not covered.
